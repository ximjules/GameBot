# GameBot

## Glavne funkcionalnosti

- registracija i prijava korisnika preko Firebase Authenticationa
- spremanje korisnickih podataka u Cloud Firestore
- dodavanje, uredjivanje i brisanje igara iz osobne biblioteke
- pretrazivanje igara preko RAWG API-ja
- dodavanje privatnih i javnih gaming dogadjaja
- pisanje, uredjivanje i brisanje biljeski/vodica
- community objave, lajkovi i komentari
- fotografiranje gaming setupa kamerom

## Tehnologije

- Kotlin
- Jetpack Compose
- Material 3
- Navigation Compose
- Firebase Authentication
- Cloud Firestore
- CameraX
- Retrofit
- Coil
